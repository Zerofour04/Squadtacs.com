# FV510 UA (Up-Armoured)

The FV510 UA is an upgraded Warrior variant featuring additional armor and a TOW anti-tank missile launcher, providing enhanced anti-armor capability.

## Specifications

| Stat | Value |
|------|-------|
| Tickets | 10 |
| Crew | 3 (Driver, Gunner, Commander) |
| Passengers | 7 |
| HP | 1500 |
| Respawn | 10 min |

## Armament

- **Main Gun**: 30mm RARDEN Cannon (AP + HE)
- **Coaxial**: L94A1 7.62mm
- **ATGM**: BGM-71 TOW

## Features

- TOW missile launcher for anti-tank capability
- Enhanced armor package
- Can engage MBTs at range
- Higher ticket cost than standard Warrior

## Tactical Notes

The TOW launcher makes the FV510 UA a serious threat to enemy armor. Use the missiles at range before closing with the autocannon.
