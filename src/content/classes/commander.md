# Commander

The Commander is the strategic leader of the entire team. Only **one Commander per team** can exist, and the role provides access to powerful support abilities that can turn the tide of battle.

## How to Become Commander

1. Must be a **Squad Leader** first
2. Open the command menu and click "Apply for Commander"
3. Other Squad Leaders vote to approve
4. Requires **majority approval** from active Squad Leaders

## Commander Abilities

Commander abilities vary by faction but typically include:

### Reconnaissance
| Ability | Description | Cooldown |
|---------|-------------|----------|
| **UAV** | Reveals enemies in a large area for a short time | ~10 min |
| **Handheld Drone** | Personal recon drone (some factions) | Varies |

### Fire Support
| Ability | Description | Cooldown |
|---------|-------------|----------|
| **Artillery Barrage** | Multiple explosive rounds on target area | ~15-20 min |
| **Mortar Barrage** | Lighter artillery strike | ~10 min |
| **Creeping Barrage** | Moving artillery line | ~20 min |

### Air Support
| Ability | Description | Cooldown |
|---------|-------------|----------|
| **A-10 Gun Run** | Devastating strafing run (USA) | ~15 min |
| **Airstrike** | Precision bombing run | ~15 min |
| **Helicopter Support** | Attack helicopter pass | Varies |

## Equipment

- Same loadout as Squad Leader
- Binoculars (essential for calling fire support)
- Smoke grenades
- Rally Point capability

## Responsibilities

1. **Coordinate overall strategy** - Work with all Squad Leaders
2. **Use abilities effectively** - Don't waste cooldowns
3. **Monitor the map** - Track all squads and enemy movements
4. **Call targets** - Mark high-value targets for abilities
5. **Maintain communication** - Keep SLs informed of the plan

## Tips for Success

### Using Fire Support
- **Always warn your team** before calling strikes
- Use **command channel** to announce: "Artillery incoming at marked location"
- Wait for friendlies to clear the area
- Target enemy HABs, vehicle concentrations, or defensive positions

### UAV Usage
- Save for crucial moments (defending/attacking key objectives)
- Coordinate timing with a push
- Mark all spotted enemies immediately

### Communication
- Don't micromanage Squad Leaders
- Give overall direction, let SLs handle tactics
- Keep command channel clear for important info
- Request updates from each squad periodically

## Common Mistakes

- Wasting fire support on single infantry
- Not communicating before strikes (teamkills)
- Ignoring Squad Leaders' input
- Using UAV when no one can act on the intel
- Staying Commander when losing (step down, let someone else try)
