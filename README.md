## About

This project started as a personal reference tool for myself and friends learning Squad. Over time, it evolved into a comprehensive wiki aimed at helping **new players** get into the game faster and **veterans** find quick references during gameplay.

The goal is simple: provide clear, practical information without the clutter.

---

## Features

| Section | Description |
|---------|-------------|
| **Guides** | Beginner to advanced tutorials (communication, tactics, vehicle combat) |
| **Factions** | All 17 playable factions with equipment and vehicles |
| **Classes** | Every role explained with tips and responsibilities |
| **Weapons** | Stats and ballistics reference |
| **Vehicles** | Armor values, crew requirements, penetration guides |
| **Maps** | All maps with tactical overviews |
| **Game Modes** | AAS, RAAS, Invasion, Insurgency, and more |

## Contributing

Contributions are welcome! There are several ways to help:

### Submit a Guide

Have tactics or knowledge to share? Submit your guide directly:

**[squadtacs.com/submit-guide](https://squadtacs.com/submit-guide)**

Guides are reviewed before publishing. You'll be credited as the author.

### Code Contributions

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes
4. Push to your branch
5. Open a Pull Request

Please keep PRs focused and describe what you're changing.

### Report Issues

Found a bug or outdated information? [Open an issue](https://github.com/Zerofour04/Squadtacs.com/issues).
